# Cabine portfolio demo

Standalone copy of the store/closet demo from `cabine_landing/site/dist`:

- `index.html`: the `.window.ext-window` markup from the Enhance section.
- `demo.js`: the store-opening sequence, replay, loader, and outfit selectors from `v2.js`.
- `demo.css`: the demo styles from `v2.css`, with compact sizing for the portfolio article.
- `assets/`: the local fonts, branding, garment thumbnails, and eight finished outfit previews used by the demo.

The portfolio embeds this document in an iframe to keep its Urbanist typography and styles isolated. All outfit choices use bundled images; the demo does not call the live AI service. It is a snapshot, so later landing-page edits must be copied here deliberately.
